# Theme Jetbrains Syntax!

Carefully crafted theme based on the comfortable feel of the Jetbrains IDEs syntax highlighting.

# Features

- First dynamically customizable theme bundle pack for Pulsar!
- Bundled light, dark and darcula themes in one!
- Automatic refresh!
- Dynamically change colors for syntax rules!

My aim is for Theme Jetbrains to be the go to best and standard community theme packs out there.
Not only will the syntax highlighting be like Jetbrains [PyCharm, WebStorm, IntelliJ etc], but also it will be customizable from the settings page in the same way that Jetbrains is.
This only styles the code editor panel (where you actually type code), NOT the full ui.  

### Intended to be used in conjunction with the Theme Jetbrains Ui package for the complete theme experience.
